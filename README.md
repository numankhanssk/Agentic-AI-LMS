
# 📚 Agentic AI-Powered Smart Library Management System

A smart, web-based library management platform that simplifies library operations through automation and Agentic AI.

Designed for Students, Teachers, and Administrators, the system offers efficient book searching, user management, issuing, returns, and intelligent library assistance.

### 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript, React.js
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **AI:** Agentic AI

### ✨ Features
- Role-based authentication
- Email OTP verification
- Smart book search
- Book issuing and return management
- Admin dashboard
- AI-powered library assistant
